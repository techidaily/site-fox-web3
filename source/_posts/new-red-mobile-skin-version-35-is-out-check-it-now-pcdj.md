## New RED Mobile Skin Version 3.5 Is Out - Check It Now! | PCDJ

[![red mobile 3.5 with pulselocker screenshot](https://i1.wp.com/pcdj.com/wp-content/uploads/2015/11/redmobile35skinpreview-coverimage.jpg?resize=530%2C298&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2015/11/redmobile35skinpreview-coverimage.jpg?fit=530%2C298&ssl=1 "redmobile35skinpreview-coverimage")

A release candidate of **RED Mobile 3.5**, our **DJ software** for Mobile DJs or DJs that require an **easy-to-use solution for just mixing music**, will launch here (check the blog) next week with a myriad of new features and GUI.

Loads of performance improvements and under-the-hood updates will be included with version 3.5, as well as tweaks to **karaoke support**, [Pulselocker streaming](http://www.pulselocker.com) support (yes RED Mobile 3 users, **Pulselocker** support is coming to RED Mobile 3.5!) and a shiny **new graphical user interface**. As always, RED Mobile 3.5 will be a free update for existing RED Mobile 3 users.

You can preview the new and improved skin below. I’m sure you can immediately see for yourself that the overall ‘default screen’ layout hasn’t deviated much from the original RED Mobile 3 design, so the transition should be seamless for existing RED Mobile 3 users. Button layout remains very much intact and the overall flat and modern design is in tune with the new **DEX 3.5 mixing software** interface.

New tabs and a **brand new work-mode** will also be included…but you’ll have to wait until the release candidate is ready next week for those items!
