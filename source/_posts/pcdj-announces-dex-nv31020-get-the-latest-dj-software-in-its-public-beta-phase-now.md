## PCDJ Announces DEX Nv3.10.2.0 - Get the Latest DJ Software in Its Public Beta Phase Now!

![](https://i0.wp.com/pcdj.com/wp-content/uploads/2018/06/reorder-user-lists.gif?fit=800%2C450&ssl=1 "reorder-user-lists")

**A new public beta of DEX 3, our top DJ mixing software, is now available for download (below)!**

To say development has been putting in a little extra time in the batcave over the last few weeks would be a massive understatement. We just launched [DEX 3 version 3.10.1.0 to the public on Monday](https://tools.techidaily.com/pcdj/products/) and here we go with a brand new public beta with a couple of new and highly-requested features — one of which has been a long time coming!

[New here? Learn more about DEX 3 and download a free trial! ![DEX 3 Daytime Skin](https://i1.wp.com/pcdj.com/wp-content/uploads/2018/06/dex3daytimeskin.jpg?fit=300%2C169&ssl=1 "DEX 3 Daytime Skin")](https://tools.techidaily.com/pcdj/products/)

Version 3.10.2.0 (finally?) introduces the ability to re-order your manually created users lists (playlists) by drag-and-drop, or you can use alphanumeric sorting by simply right-clicking on any user list. Also included is exporting lists as CSV or M3U (playlist) files. This means DJs and karaoke hosts can create karaoke song books or song lists with very little time and editing.

As is always the case, version 3.10.2.0 includes a few minor bug fixes and under-the-hood performance improvements.

Since version 3.10.2.0 is considered a ‘[Public Beta](https://en.wikipedia.org/wiki/Software%5Frelease%5Flife%5Fcycle)‘ you will want to test thoroughly before going live. With that said, our staff has been mixing music and video with version 3.10.2.0 (very loudly, I might add – we’re trying work here! 🤨) for the last few days without issue. If you happen to run into any issues please [join the Official PCDJ User Group](https://tools.techidaily.com/pcdj/products/) and report the problems there directly. If you need to roll back to the prior public release you can do so from the [DEX 3 support page](https://tools.techidaily.com/pcdj/products/).

### New, Changed, or Fixed in DEX 3 Version 3.10.2.0

* Reorder user lists (playlists) in the browser by dragging them with the mouse
* Alphanumeric sorting of the user lists in the browser (right-click on a list for the option)
* Export lists as CSV / M3U (right-click on the list contents for the  
option) – eg. you can use this to export a karaoke book in CSV format that you can process/edit and then print
* Minor bug fixes and performance improvements
